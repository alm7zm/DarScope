# Project SE411 (Fall 2026-27): Part 2 brief

The course brief for Part 2, copied word for word from the instructor's file `project description Part 2.pdf`.

## Description

In the second part of the project, you will create a Java Spring Server for your frontend (first part of the project) and integrate both parts to work together. The final application has to satisfy these requirements:

1. The Java application is a Spring server.
2. The user of the application can add an element.
3. The user of the application can search for an element by id.
4. The user of the application can search for all elements and displays paginated results.
5. The user of the application can update an element.
6. A Unit tests suite allows to test all the backend (Junit + Mockito).

## Teams

Groups should be made of three students.

Only one student submits the project as a github public repository.

## Final Presentation

Prepare a presentation with:

1. A design of the overall architecture of your system
2. A table that describes your REST API routes similar to the one in lab14.

So only two slides with oral explanation. Then prepare a demo of the tool and I'll ask you some questions about the code.
